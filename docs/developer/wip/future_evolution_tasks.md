# Ollivander SoC Generator - Future Evolution Tasks

This document tracks possible future architectural improvements and features for the Ollivander SoC Generator.

---

## 1. Extension of the SystemVerilog Intermediate Representation (SV-IR)

The structural SystemVerilog Intermediate Representation (SV-IR) is currently restricted to validating and rendering the digital top-level wrappers (`crossbar_soc_top.sv` and `noc_soc_top.sv`). To establish complete structural validation across all generated wrappers, the SV-IR should be extended to cover the physical chip wrapper (`*_chip.sv`) and the universal Network-on-Chip node wrapper (`universal_tile.sv`).

### 1.1 Physical Top-Level Wrapper (`*_chip.sv`)
The physical wrapper instantiates the digital SoC core (`<project_name>.sv`), the padframe (`<project_name>_padframe.sv`), and the physical clock generators (e.g., PLLs, FLLs, crystal oscillators, and clock multiplexers).

#### Advantages
*   **Core-to-Padframe Interface Validation**: Enables static structural checking to verify that all digital ports exported by the SoC core map to the correct internal ports of the padframe (preventing pinout and naming mismatches).
*   **Clock and Reset Tree Validation**: Formally verifies the routing of clock generator outputs (e.g., PLL divided outputs) to the clock inputs of the digital core, and the connection of PLL status/lock signals to the system reset generators (`rstgen`).
*   **Parameter Verification for Clock IPs**: Inspects and validates parameter mappings (such as division ratios, lock counters, and bypass flags) against the clock generator cell models or technology catalogs.
*   **Unified Code Generation**: Replaces the legacy Mako-template string interpolation for `*_chip.sv` with the standard SV-IR rendering engine, improving code maintainability.

#### Difficulties & Mitigation Strategies
*   **Temporal Build Dependency on Padrick**: The padframe RTL is generated by Padrick. The SV-IR cannot parse the padframe's ports until Padrick has written the files.
    *   *Mitigation*: The python orchestrator must ensure Padrick runs and writes the padframe sources before constructing the `*_chip.sv` IR. The `pyslang` parser can then compile the generated padframe wrapper signature dynamically.
*   **Handling of Mixed-Signal and Bidirectional Ports**: Padframes utilize bidirectional (`inout` tri-state) pins and analog lines (e.g., external loop filters, power rails, references). The current SV-IR data model is optimized for unidirectional digital signals (`logic`).
    *   *Mitigation*: Extend the `TopSignal` and `PortConnection` classes in `sv_ir.py` to support bidirectional signal types and analog bypass connections without triggering type-compatibility warnings.

### 1.2 Universal NoC Node Wrapper (`universal_tile.sv`)
The universal tile encapsulates the local NoC routing infrastructure, instantiating the router, local Network Adapters (NIs), and protocol conversion modules.

#### Advantages
*   **Router-to-NI Interface Verification**: Verifies that the internal links between the local router ports and the Network Adapter are wired correctly.
*   **Local Parameter Coherence**: Ensures critical NoC parameters (e.g., flit width, virtual channel count, and packet payload sizes) match between the router and adapter instances.
*   **Clock and Reset Domain Check**: Validates the instantiation of clock dividers, clock gating cells, and Clock Domain Crossing (CDC) synchronizers within the local node.

#### Difficulties & Mitigation Strategies
*   **Engineering Overhead**: The internal structure of the `universal_tile.sv` is highly regular and static. Writing a dedicated Python builder for this module adds development complexity for a component that has a low probability of manual configuration errors.
    *   *Mitigation*: Keep the tile builder simple and standalone. Since the tile is rendered once as a parameterized module, the IR only needs to be constructed once per compile, avoiding grid-dependent boundary checking (which is already resolved and validated at the top-level digital wrapper).
